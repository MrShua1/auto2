# User Delivery Preferences

- Do not create delivery previews, HTML overview pages, preview galleries, or delivery contact sheets. Deliver the requested files and concise file/directory links instead, unless the user explicitly changes this preference.
- Preserve the user's requested segment granularity. A SEG may contain multiple storyboard shots; do not automatically promote every shot into a separate SEG or add a larger episode/unit folder above SEG when SEG is the requested maximum delivery unit.
- Every future Auto delivery must bundle all required tools, skill modules/resources, pinned runtime dependencies, installation and readiness tests. Missing required capabilities still block the corresponding stage; never bypass the gate with an ad hoc API call.
- Supplied notices, posters, letters, cards and banners must be integrated into relevant scene/prop images with role-bound original references, not merely archived or mapped. Preserve source text and record conflicts; do not fabricate policy content, signatures or approvals.
- Auto image generation should use a lightweight per-batch preflight and automatically regenerate failed image jobs, defaulting to at most three total attempts per job with recorded cost uncertainty. Do not weaken tool/credential, source-fidelity, content-safety or final-approval gates, and never retry videos under this image policy.
