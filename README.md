# Auto2 影视生产套件 (Auto2 Suite · SD 2.0 专用版)

本仓库为 **Auto2 工业级影视分集与预视频工程套件**。专门服务于 **Seedance 2.0 (SD 2.0)** 及同类 15 秒时长上限的短视频大模型，提供超精细化分段切片、微观物理动作转译与全流程硬核校验门禁。

---

## 核心定位与技术规范差异

| 规范维度 | 原 Auto-STX 规范 (SD 2.5 / WAN 3.0) | **新 Auto2 规范 (SD 2.0 专用)** |
| :--- | :--- | :--- |
| **适配模型** | Seedance 2.5 / WAN 3.0 Prime 等长视频模型 | **Seedance 2.0 (SD 2.0)** 等 15 秒上限模型 |
| **单分段时长 (SEG Duration)** | 15 ~ 28 秒（极值 30 秒） | **11 ~ 15 秒（严格大于 10 秒，且 ≤ 15 秒）** |
| **单段分镜镜头数** | 2 ~ 4 个镜头（部分 5~6 镜） | **2 ~ 3 个镜头**（单镜 3~6 秒黄金区间） |
| **单段台词容量基准** | 20 ~ 45 字（超 45 字跨段拆分） | **15 ~ 35 字**（超 35 字强制跨段拆分） |
| **单集分段数量估算** | 2 ~ 3 个 SEG（60~80s 剧本） | **4 ~ 6 个 SEG**（相同剧本更精细切片） |
| **校验器门禁阻断** | 拦截 < 15s 或 > 30s | **拦截 ≤ 10s 或 > 15s**（Exit Code 1） |

## 核心法则与质检门禁（Quality Gates）

1. **Rule 0.16 身体/面部朝向硬锁门禁**：所有镜头出镜角色必须在 `【位置承接】` 显式声明朝向与视线，杜绝模型无序漂移。
2. **Rule 0.17 物理空间锚点景深守恒门禁**：全面肃清孤立模糊方向词，单个分段内空间物理锚点景深绝对守恒。
3. **Rule 0.18 台词口型物理咬合与内心独白（OS）隔离门禁**：现场原声对白必须联动唇形张合发声；内心独白（OS）严格双唇闭合。
4. **Rule 0.19 SD 2.0 10~15秒台词容量与分段边界门禁**：单段时长刚性锁定 11~15s，台词 15~35 字，镜头 2~3 个。
5. **Rule 0.20 介质透视主客观解耦防飞鱼门禁**：大俯角垂直向下俯视水面（0天空、0人物），海底沙石游曳，彻底消灭飞鱼上天穿帮。
6. **Rule 0.21 站位与起始状态绝对禁入穿着声明门禁**：服装 100% 由角色参考卡定义，严禁文字篡改或二次引导。
7. **最高绝对红线：严格 0 视频生成**：全流程交付纯净预视频结构，严禁 `--run` 与视频任务提交。

## 服务器端（Ubuntu / Linux）安装与使用

### 1. 克隆本仓库
```bash
git clone git@github.com:MrShua1/auto2.git auto2
cd auto2
```

### 2. 执行安装脚本
默认安装至 `~/.config/opencode`：
```bash
chmod +x install-linux.sh
./install-linux.sh
```

### 3. 重启并验证
重启 OpenCode 宿主：
```bash
opencode serve
```
验证可用命令与技能：
* `/分集` 或 `/分镜`：触发 Auto2 剧本到预视频工程（10~15s SD 2.0 模式）
* `/stx`：触发 STX 高性能生图通道
