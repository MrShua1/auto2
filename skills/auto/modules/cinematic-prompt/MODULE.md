# Cinematic Prompt Module

Internal Auto module for observable camera, lens, depth, lighting, color,
texture, realism, LOOK transfer and anti-slop language in still prompts.

Read `SOURCE-SKILL.md` and local supporting files only when a still-image LOOK
stage needs them. Preserve the bundled `LICENSE` and attribution. Do not invoke
the original external Skill. This module may not change story state, identity,
wardrobe, blocking, geography or user locks, and its restrictions do not alter
Auto's selected image execution route.

Auto has no Skill-wide genre or LOOK default. Every still-image prompt ends with the
observable LOOK suffix locked in the current project's `productionProfile`.
This suffix constrains rendering, palette, lighting and medium only; it cannot alter
identity, wardrobe, story state, blocking, geography or chronology. When a still
prompt depicts a state change or a changed appearance, describe the visible
pre-change condition before the changed result.
